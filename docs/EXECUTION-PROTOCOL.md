# TINO Backend — SDD Execution Protocol

1. Ler `security/SECURITY-GIT-SAFETY-POLICY.md`.
2. Ler Architecture Baseline.
3. Ler ADRs relevantes.
4. Ler System Specs relevantes.
5. Ler apenas o milestone autorizado.
6. Declarar SELECTIVE ROUTE.
7. Reportar cobertura/plano antes de editar.
8. Implementar somente `IN SCOPE` e remover vazamento futuro.
9. Executar testes e gates de arquitetura/dados.
10. Revisar diff, executar secret scan e revisar staged files antes de commit.
11. Revisar novos commits, executar secret scan e auditar arquivos inesperados antes de push.
12. Exigir security gate local e CI em PASS antes de milestone/merge PASS.
13. Produzir Evidence objetiva sem copiar credenciais.
14. Reportar `PASS` ou `BLOCKED`.
15. Parar.
16. Nunca iniciar o milestone seguinte sem autorização explícita.
