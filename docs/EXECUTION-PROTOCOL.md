# TINO Backend — SDD Execution Protocol

1. Ler Architecture Baseline.
2. Ler ADRs relevantes.
3. Ler System Specs relevantes.
4. Ler apenas o milestone autorizado.
5. Declarar SELECTIVE ROUTE.
6. Reportar cobertura/plano antes de editar.
7. Implementar somente `IN SCOPE` e remover vazamento futuro.
8. Executar todos os gates.
9. Produzir Evidence objetiva.
10. Reportar `PASS` ou `BLOCKED`.
11. Parar.
12. Nunca iniciar o milestone seguinte sem autorização explícita.
